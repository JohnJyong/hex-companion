# 版本记录

## 0.7.0 独立数据更新

「设置与数据」显示正在使用的数据编号、游戏补丁和统计截止时间。安装一次 0.7.0 后，英雄与海克斯目录、图标、三类胜率及装备统计、攻略、联动规则和出装模板可以单独更新。默认每 6 小时检查，也可手动检查。进行中的识别沿用原版本，下载完成的数据可在下次启动或停止识别后启用。更新中断时继续使用本地资料。

首批在线数据为 26.23，包含 4,991,976 局，统计截至 2026-11-20 08:00（北京时间）。首次离线启动提供内置 26.22。项目每 12 小时在 GitHub Actions 核对上游发布，攻略和规则修订随资料分支发布。

## 0.6.1 局内评分与选人标签

海克斯卡片的浮层缩窄并对齐到标题上方。首行显示选择建议和同阶排名，主体显示胜率、样本数及相对英雄基准的差值。缺少样本时显示机制适配分。已选联动或触发条件显示在卡片底部。选人队列和备选席使用对齐的胜率数字与等级徽标，本人行有金色标记。

## 0.6.0 局内出装与跨轮搭配

开启对局识别，切回游戏后，右上角「推荐出装」显示英雄、下一件成装、整件价格和后续两件。接口明确返回海克斯模式时，第一轮选卡前就能看到出装。部分客户端只报告大乱斗，助手会等到首次认出三张海克斯再显示。面板关闭后仍能查看出装。开启装备同步后，购买成装会推进路线。若本机接口不可用，手动选择英雄并成功识别第一轮候选也能显示出装。主窗口侧栏「推荐出装」可直达六格路线。

本轮卡片确认后，在游戏中按 `Ctrl+Alt+1/2/3` 记录准备选择的左、中、右项，然后点击该卡。右上角会显示已记数量。下一轮会逐张与已记录的符文核对，同时考虑英雄适配、装备和样本。例如已有火上浇油时，易损候选会提示普攻灼烧可以暴击。可核实的直接联动、机制冲突和共同收益方向在卡片上分别标注。工作台上可打开完整匹配的搭配攻略，回看触发条件。在主窗口预览候选只改变预览路线，局内继续显示已记录的方案。

## 0.5.0 选人胜率

在选人前打开 Windows 助手，保持英雄联盟客户端处于前台。国服中文选人界面出现「可用」英雄栏后，左侧每位已辨认的队友旁显示英雄胜率和全英雄排名，顶部已辨认的备选头像下显示胜率。本人的金色称号行会标「我」。换人或交换英雄后会重新读取。选人提示默认开启，开关位于「实时识别 → 选人阶段」，会记住关闭选择。Ctrl+Alt+H 或 F8 可以临时隐藏和恢复浮层。

数据采用与英雄榜相同的常规海克斯大乱斗 26.22 全体样本。S/A/B/C/D 根据英雄排名前 10% / 30% / 60% / 85% / 其余分档，低样本不分档。例如提莫的快照胜率为 53.6%，第 15/173。个人账号战绩不参与计算。普通大乱斗可能使用相同的选人布局，所显示的百分比始终来自标注的海克斯快照。

选人单独检测前台 LeagueClientUx 窗口，按客户区尺寸读取顶部头像和左侧称号两块区域。它不需要先连接对局窗口，也不需要读取账号凭据。当前适配中文、标准 16:9 客户端；空位或无法确认的英雄不显示标签。切到其他程序或进入游戏后选人标签收起，对局内海克斯识别仍按下文启动。

## 0.4.1 识别提速

首次看到三个同阶标题后，助手立即转到三张卡的标题高度复核。一字近似时也能先定位，直到连续三帧确认后才给出评分。标题带覆盖设定区域的完整宽度，便于识别重随后变长的名称。卡片关闭后，助手会在上轮已确认的位置查找，并约每两秒扩大一次搜索范围，以便找到移位的面板。

实时识别页显示当前在定位面板、跟踪标题还是复用相同画面。导出的本地诊断包含客户区和识别图片的尺寸、截图和 OCR 耗时，以及主窗口返回识别结果的时间；诊断文件不含截图。

用同一张 2189×1123 游戏截图在 Apple M5 Pro 上离线回放，每版三次，从首次采样到确认「升级：无尽之刃、轻拍背部、捐赠」的中位时间由 2.04 秒降至 0.91 秒。旧版读三次整图，新版读一次整图、两次标题带。在另一组静止回放中，确认后两秒内的额外 OCR 由 8 次降至 0 次。测试使用生产识别和确认逻辑，以内存 PNG 模拟窗口取图，未计入模型初始化、Windows 截屏和浮层绘制。

## 0.4 攻略库

打开侧栏「攻略库」可以按英雄、海克斯、装备或关键词离线检索，也可以筛选本局英雄或含装备说明的条目。候选的「查看推荐依据」展示与该选项相关的攻略，记录选择或预览出装后，装备栏会列出符合当前条件的出装笔记。每条都保留原文链接和核对日期。旧版本教程可在攻略库查阅，未注明版本的经验会标记为阅读参考。

2026-11-18 整理了 22 条中文攻略笔记和 420 条社区搭配索引。笔记的适用条件与装备均在 `app/data/editorial-guides.json`；开放下载的社区目录在 `app/data/community-guides.json`。索引保留英雄、资料库中可核实的海克斯和原作者标签，包括慎选及娱乐玩法。攻略作为选法和出装的参考，统计数据与机制分沿用各自的计算口径。

开发者可运行 `python3 scripts/import-community-guides.py` 重新校验、生成开放目录；`--offline --checked-at 2026-11-18` 可使用本机已下载的相同快照复现本次结果。新发行需复核来源版本和映射后导入，攻略笔记由人工对照原文维护。Windows 软件包内置这批资料。

## 0.3 修复内容

- 首次识别完整游戏客户区，找到候选后按实际标题坐标缩小到标题条；已确认且画面未变时复用结果，定期重新核对。截图识别、对局数据和按键检测独立运行，游戏接口等待不会堵住隐藏操作。
- 三个独立、鼠标穿透的标签跟随三张卡片，支持物理坐标转 Windows 缩放坐标；更新文本不会反复显示窗口。`Ctrl+Alt+H` 或 `F8` 隐藏后，后续识别不会自动重新显示，也可用主窗口隐藏按钮。
- 短暂漏读最多保留 **1.5 秒灰色“待复核”结果**，期间禁止记录；识别到新候选时撤下旧推荐，避免闪烁与误记。
- 接入真实英雄 × 海克斯胜率、样本、同阶排名及 pp 差值。缺统计时明确显示暂无数据，机制适配分继续单独展示。
- 修复亚索被通用三相战士模板主导的问题。默认参考该英雄真实核心装备；选择“升级：无尽之刃”后优先无尽，神射法师不会把低法强收益的亚索强行改成纳什／帽子路线。升级后的魔切、炽天使和末日寒冬也能继续计入已有装备。

本次针对反馈的 **2560×1440、100% 缩放、无边框** 环境修复。在开发机上，用提供的约 2.2K 宽游戏截图做离线图片测试，完整画面 OCR 约 **611–709 毫秒**，定位后的标题条约 **47–72 毫秒**。这不是 Windows 截图到标签显示的端到端测量，也不代表所有画面的速度或准确率；仍需在实际游戏中复测。
